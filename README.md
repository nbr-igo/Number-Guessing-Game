# Number Guessing Game
A simple command-line number guessing game developed in Java. 
This project runs in the terminal/command prompt - no GUI, just pure console fun.

### 🎮 Features:<br>

✅ Random number generation within a specified range<br>
✅ Input validation for numbers<br>


### 🧩 Future Improvements:<br>

✨ Add a test case for when the minimum number is greater than the maximum (and vice versa)<br>
✨ Handle empty input more gracefully to avoid repeated prompts when pressing Enter without typing a number<br>
